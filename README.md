## 🔐 About PFE

PFE is a mathematical encryption system based on a new analytical 
criterion for prime numbers. It does not rely on integer factorization 
or discrete logarithms, making it resistant to quantum computing attacks.

## 🧮 Core Principle

A single continuous analytical function that vanishes precisely at primes:

    y(x) = -sin²(π · (Γ(x)+1)/x) / cosh(x)

    y(n) = 0   ⟺   n is prime
